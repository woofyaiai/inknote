# 字在 Inknote

可加入 iPhone 主畫面的文字貼紙工具。輸入文字、選擇樣式，產生透明 PNG 圖片，複製或儲存後貼到 Instagram 限時動態。

## 使用方式

首次以 Safari 開啟網站，等候「離線已準備好」，從分享選單加入主畫面。之後可離線編輯、匯入本機字體、收藏樣式及輸出圖片。初次準備含約 12 MB 的基本字體；新增九款可選擇下載，全數約 24 MB。字體面板會標示離線狀態。更新及發佈 IG 需要網路。

畫面開啟後直接輸入文字，選擇風格、字體、排版、顏色和效果。「複製貼紙」產生透明圖片；「儲存圖片」提供系統分享與 PNG 下載。分享選單開啟不代表已經存入相簿，請完成儲存動作。

## 已製作功能

- 中文、英文與組合 emoji，多行輸入及即時預覽。
- 12 款字體（8 款支援繁中、4 款英文）；分類、常用收藏與按需下載；從手機匯入 TTF／OTF，檢查重複、刪除及缺字提示。
- 12 款風格，收藏、改名及刪除；字級、字距、行距、文字區寬度及對齊。
- 六種底色效果：整段標籤、字形包邊、雙層貼紙、逐行底色、連接式底色及螢光筆。
- 平直、波浪、階梯、直排；字形包邊可跟隨彩色 emoji 輪廓。
- 文字顏色、圓角、底色濃淡、留白、文字外框與陰影。
- PNG 圖片複製、分享與下載；透明度與效果留白。
- 自動保存最後草稿；完整備份與還原草稿、收藏、匯入字體。
- 離線準備狀態、加入主畫面、繁體中文手機介面。

網站公開、免登入。自己的字體、草稿、收藏存於目前瀏覽器的裝置資料，沒有作品上傳或追蹤分析。其他訪客不會看到這些資料。清除網站資料、裝置遺失或瀏覽器回收資料可能造成遺失，請自行保存備份。備份檔含私人內容，勿放入公開專案。Safari 與加入主畫面的應用是否共用資料可能受系統行為影響，建議固定從主畫面使用，需要搬移時使用備份。

## 範圍與限制

- 每份最多 2,500 個文字輸入單位；極長內容會提示分張，避免手機記憶體不足。
- 匯入字體每檔 20 MB、共 80 MB、最多 20 個；收藏最多 100 款。
- 一組文字共用樣式；emoji 優先使用系統彩色字體，一般文字外框不套在 emoji 上；底色包邊與雙層貼紙則跟隨完整 emoji 輪廓。
- 已完成瀏覽器自動檢查；Safari、iPhone 與 IG 貼入透明圖片需依 [手機測試](IPHONE_TEST.md) 實機驗證。未宣稱 IG 相容性已通過。
- 沒有伺服器帳號或跨裝置自動同步；備份還原會在確認後取代原資料。

## 發布與維護

本專案是純靜態網站，適合 GitHub Pages，不需要額外製作步驟。請看 [GitHub 發布指引](GITHUB_SETUP.md)。內建字體授權保留在 [字體來源](FONTS.md)。

更新網站時同時更新 sw.js 與 app.js 的快取版本名稱，目前為 inknote-v2，確保新版本完整取得。HTML 與模組資源的版本查詢參數也要一起更新。目前保留 v1 資源快取服務尚未關閉的舊頁面，避免新舊程式混載。不要刪除或更名 storage.js 的本機資料庫，除非另提供資料移轉。每次更新後驗證舊草稿、收藏與字體仍可使用。

公開專案只放程式、通用說明及內建授權字體；不得加入個人備份、憑證、草稿或私人字體。

公開字體的備份保存選擇與識別，不含全部公開字體檔。換裝置還原後需重新下載；私人匯入字體仍完整包含於備份。詳見 [更新紀錄](CHANGELOG.md)。
